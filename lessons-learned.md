# Lessons learned and improvement opportunities

## Classroom pilot

The interactive Slides adventure was used with a seminary class. The facilitator described the experience as having gone **only okay**. This is qualitative feedback, not a measured usability or learning result.

## What this prototype demonstrates

- A quick way to test a classroom game without a custom web app
- Simple branching logic and retry feedback using slide hyperlinks
- A metaphor-driven progression from visible choices to uncertainty
- A discussion prompt anchored in Daniel 3:17–18

## Candidate improvements (not yet validated)

1. **Clarify the first interaction:** Make the initial button and click instruction more prominent
2. **Reduce friction:** Test every branch and restart link from slideshow mode on phones and computers
3. **Improve game feel:** Consider a lightweight HTML version if actual movement and obstacle avoidance are needed
4. **Observe engagement:** Ask students which obstacle was most meaningful or confusing
5. **Connect to discussion:** Reserve a short debrief on faithfulness despite uncertain outcomes

## Iteration note

These are proposed changes, not claims about what specifically caused any classroom difficulty. Future testing can distinguish navigation friction from activity-design issues.
